# 小狐狸 QQ 机器人 · 用户使用指南

> 适用版本：Jianer NEXT 3.1 + 本轮新增功能（引用回复 / 音色扩展 / 用户档案 / 模型切换）
> 最后更新：2026-10-04

---

## 一、怎么和它说话

| 场景      | 怎么触发                                 |
| ------- | ------------------------------------ |
| **私聊**  | 直接发消息就行，不用加前缀（首次会先问你一句"愿不愿意聊"，回一句即可） |
| **群聊**  | 需要在问题前面加命令前缀，默认是 `~`。例如 `~今天天气怎么样`   |
| **@ 它** | 群里 `@小狐狸 ~帮助` 可以看帮助菜单                |

---

## 二、私聊专属的三个特性

这三个只在**私聊**生效。

### 1. 每条回复都会引用你的消息

它的回复会自动带上引用（QQ 里显示为"回复某人"），这样多轮对话不会串行。

### 2. 名字下方显示「正在输入…」

它在思考时，对方会看到「正在输入中…」。这是 QQ 原生能力，只在好友之间生效。

### 3. 消息流里的「正在思考中……」思考气泡

如果它思考**超过 1.5 秒**，会先在聊天里发一条 `正在思考中……` 气泡，回复到手后**自动撤回**，再发正式回复。

- 秒回的对话**不会有任何痕迹**（根本不会发气泡）
- 慢回复你会看到 `正在思考中……` 出现又消失，随后是「对方撤回了一条消息」

## 三、说话和听声

### 它听得懂语音

直接发一条 QQ 语音，它会**自动转成文字**再回答。全程在本机离线识别，不上传。

现在**还没有**在聊天里回显识别结果；如果它答非所问，多半是识别错了，可以再发一遍或打字。

### 让它念出来

| 命令                     | 作用                      |
| ---------------------- | ----------------------- |
| `~语音 你好呀`              | 用当前音色朗读                 |
| `~语音 音色:晓晓 语速:1.3 你好呀` | 指定音色和语速                 |
| `~语音开` / `~语音关`        | 开启后，**所有回复都用语音**（不再发文字） |

### 换音色（本轮重点扩展）

发 `~音色` 看清单。现在有 **22 个可用音色**（启动时自动检测，不能出声的不会列出来）：

- **普通话**：小艺、晓晓、晓萱、云希、云扬、云健、云夏
- **方言**：东北话、陕西话
- **粤语**：粤语·晓曼、粤语·晓佳、粤语·云龙
- **台湾腔**：台湾腔·晓臻、台湾腔·晓雨、台湾腔·云哲
- **日语**：日语·七海、日语·圭太
- **英语**：英语·Aria、英语·Guy、英音·Sonia
- **韩语**：韩语·善熙、韩语·仁俊

**11 种趣味音效**，可以和任意音色叠加：

| 用法           | 效果                              |
| ------------ | ------------------------------- |
| `~音色 东北话`    | 换音色                             |
| `~音色 花栗鼠`    | 只加音效（保留当前音色）                    |
| `~音色 晓晓+花栗鼠` | 音色 + 音效叠加                       |
| `~音色 随机`     | **每次回复随机换一个音色**                 |
| `~音色 情绪`     | **按回复内容自动挑**（开心用晓晓、难过放慢、生气换大叔音） |
| `~音色 检测`     | 立即重新检测哪些音色可用                    |

音效清单：花栗鼠、萝莉、大叔、低沉、机器人、电音、山洞、混响、电话、慢速、快速。

> 小提示：选了英语/日语音色但让它念中文时，它会**自动回退到中文音色**保证有声音，不会变成机械音。

## 四、切换模型（暂时不可用）

| 命令           | 作用                             | 权限   |
| ------------ | ------------------------------ | ---- |
| `~模型`        | 看全部模型 + 各供应商健康状态               | 所有人  |
| `~模型 推理`     | 切到推理模型（**只影响你自己**）             | 所有人  |
| `~模型 3`      | 按清单序号切                         | 所有人  |
| `~模型 自动`     | 开启智能路由：短问题走快模型、推理类走推理模型、带图走多模态 | 所有人  |
| `~模型 群 <名>`  | 设置**本群默认**                     | 管理员  |
| `~模型 全局 <名>` | 设置**全局默认**                     | ROOT |
| `~模型 状态`     | 探活所有供应商                        | 管理员  |

**优先级：你个人的选择 > 本群默认 > 全局默认。**

⚠️ 切换模型会**重置你自己的对话上下文**（不同模型的历史格式不兼容），这是故意的。

`~云端` / `~本地` 仍然可用，是切换后端的快捷方式。

## 五、它会记住你

它给每个聊过的人建了一份档案，并在对话时参考，所以它**会记得你是谁、你是老熟人还是新朋友**。

| 命令       | 作用                           |
| -------- | ---------------------------- |
| `~用户`    | 看自己的档案（昵称、关系、好感度、发言数、连续互动天数） |
| `~叫我 明明` | 让它以后这么称呼你                    |
| `~忘记我`   | **物理删除**关于你的全部记录             |

**好感度**：聊天 +1、发语音 +2、被夸 +3、连续互动有加成，每日上限 30。档位：陌生 → 眼熟 → 熟人 → 挚友。

## 八、常见问题

**Q：它不回我？**
① 私聊首次需要先回一句同意；② 群里要加 `~` 前缀；③ 看启动窗口有没有报错。

**Q：`~音色` 里没有我想要的音色？**
启动时会自动检测哪些音色能出声，不能的不会列出。发 `~音色 检测` 可以重新检测。

**Q：语音没声音／变成机械音？**
① 检查是否联网（微软神经语音需要联网）；② 用 `~音色 晓晓` 换回中文音色；③ 看启动窗口是否有 `[本地TTS]` 报错。

**Q：换了音色没反应？**
确认发的是 `~音色 名字`（有空格）。设置是按会话保存的：私聊只影响你自己，群里只影响那个群。

**Q：怎么让它别看群里的某些消息？**
管理员用 `~休眠`，它就不再回应，直到有人发 `~` 开头的消息。

**Q：我的聊天记录会被上传吗？**
文字会发给所配置的 AI 服务商（云端模式）；**语音转文字全程在本机离线完成，不上传**。用户档案只存在本机 `data/fox.db`，发对话时只带 2~3 行摘要。发 `~忘记我` 可彻底删除。
